# Hannah Weiss

Senior Product Manager (Technical) · Berlin, Germany
hannah.weiss@example.com

## Profile

I am a technical product manager with six years in product, after two
years as a backend developer. I work best on platform and developer-
facing products, where understanding the system matters as much as
understanding the customer. I am comfortable reading code, writing API
specifications and discussing trade-offs with engineers, and equally
comfortable running discovery interviews and presenting a roadmap to
leadership.

## Experience

**Senior Product Manager, Payments API — Zahlwerk GmbH, Berlin (2023 to
present).** I own the public payments API used by around 4,000
merchants and their developers. I set the roadmap with two engineering
teams, and in my first year we shipped a redesigned onboarding that
took a merchant's time to first successful payment from four days to
under one. I introduced API usage analytics and a quarterly developer
survey, which became the main input to our prioritisation, and led the
deprecation of our oldest API version without losing a single top-100
merchant. I write the specifications for new endpoints with the tech
leads and run a monthly review of developer support tickets with the
support team.

**Product Manager, Developer Tools — Cloudnest, Berlin (2020 to 2023).**
I managed the command-line tool and SDKs for a cloud hosting company.
I ran discovery with customers, defined requirements, and worked with
one engineering team through two-week sprints in Jira. Our redesigned
CLI raised weekly active usage by 70% over a year.

**Backend Developer — Cloudnest, Berlin (2018 to 2020).** I built
Python and Go services for the billing system before moving into product.
