a high-traffic consumer platform reliable. My work sits between
software engineering and operations: I write code to automate
operational work, design alerting that wakes people up only when it
matters, and lead incident reviews that lead to real fixes.

of a five-person SRE team supporting about 80 microservices on Google
Kubernetes Engine. I rebuilt our alerting around service-level
objectives, which cut pages by 60% while catching more real incidents,
and wrote the load-testing setup with k6 that we now run before every
major on-sale. I take part in the on-call rotation, have led more than
twenty incident reviews, and wrote Go tooling that automates database
failover drills on Cloud SQL.

**Junior DevOps Engineer, Softhaus, Warsaw (2022 to 2023).** I
maintained Jenkins pipelines, wrote Terraform for GCP projects, and
supported developers with Docker and Kubernetes questions.
