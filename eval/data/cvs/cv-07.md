# Jonas Becker

Frontend Developer, Berlin
jonas.becker@example.com

## About me

Frontend developer with five years of experience building web apps in
React and TypeScript, mostly for B2B software. I like turning complex
workflows into interfaces people can use without a manual, and I care
about accessibility and performance as part of the job rather than an
afterthought.

## Work

**Frontend Developer at Lumora Analytics, Berlin (since September 2022)**

Lumora makes reporting software for logistics companies. I work in a
team of six on the main web application, which is written in React with
TypeScript and uses Redux Toolkit for state and React Query for data
fetching. Over the last year I led the rebuild of our report builder,
replacing a jQuery-era drag-and-drop editor with a React implementation
that customers now use to create about 9,000 reports a month. I set up
our end-to-end tests with Cypress, introduced Storybook for our shared
components, and audited the app against WCAG 2.1 AA with our designer,
fixing more than 120 accessibility issues. I also moved our build from
Webpack to Vite, which cut local start-up time from about 40 seconds to
under 5.

**Junior Web Developer at Kreuzberg Digital, Berlin (2021 to 2022)**

An agency job building marketing sites and small web shops. I wrote
HTML, CSS and JavaScript, built my first React projects, and learned how
to work directly with clients on changes and deadlines.
